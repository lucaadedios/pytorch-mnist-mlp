# PyTorch MNIST MLP

This project was my first deep learning model built in PyTorch. The goal wasn't to maximize accuracy, but to understand the core architecture of a multilayer perceptron (MLP) and how the entire training pipeline works.

I built the model from scratch using `nn.Module`, trained it on the MNIST handwritten digit dataset, and worked through concepts like forward propagation, backpropagation, gradient descent, loss functions, optimization, and model evaluation.

## What I Learned

- Building an MLP in PyTorch
- The PyTorch training workflow
- Forward and backward propagation
- Loss functions and optimizers
- Training vs. validation vs. test evaluation
- Hyperparameter tuning and model performance

This project serves as a foundation before moving on to more advanced architectures like CNNs, Transformers, and memory-augmented models.
